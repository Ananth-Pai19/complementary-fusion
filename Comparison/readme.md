## Comparison Study

This is a comprehensive comparison study evaluating the denoising methods proposed in the reference literature we followed:

### Denoising Methods Evaluated

1. **TGV** (Total Generalized Variation) — [Denoising optical coherence tomography using second order total generalized variation decomposition](https://www.sciencedirect.com/science/article/pii/S1746809415001664) (Duan et al., 2016)
2. **NLM** (Non-Local Means) — [Non-Local Mean Denoising Algorithm Based on Fractional Compact Finite Difference Scheme Effectively Reduces Speckle Noise in Optical Coherence Tomography Images](https://www.mdpi.com/2072-666x/13/12/2039) (Chen & Gao, 2022)
3. **Wavelet-PSO** (Wavelet Particle Swarm Optimization) — [Retinal Optical Coherence Tomography Image Denoising Using Modified Soft Thresholding Wavelet Transform](https://www.iieta.org/journals/ts/paper/10.18280/ts.400334) (Subhedar et al., 2023)
4. **K-SVD** (K-Singular Value Decomposition) — [Denoising algorithm of OCT images via sparse representation based on noise estimation and global dictionary](https://pubmed.ncbi.nlm.nih.gov/35209533/) (Zhang et al., 2022)

---

### Evaluation Metrics

* **PSNR** (Peak Signal-to-Noise Ratio)
* **SSIM** (Structural Similarity Index)
