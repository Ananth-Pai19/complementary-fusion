## Comparison Study

This is a comprehensive comparison study evaluating the denoising methods proposed in the reference papers we followed:

### Denoising Methods Evaluated

1. **TGV** (Total Generalized Variation)
2. **NLM** (Non-Local Means)
3. **Wavelet-PSO** (Wavelet Particle Swarm Optimization)
4. **K-SVD** (K-Singular Value Decomposition)

---

### Evaluation Metrics

* **PSNR** (Peak Signal-to-Noise Ratio)
* **SSIM** (Structural Similarity Index)
* **EPI** (Edge Preservation Index)
